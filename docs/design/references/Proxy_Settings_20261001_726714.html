BlindBox 用户服务协议与隐私政策

生效日期：2026年10月1日 | 版本号：v2.0

第一条 定义与总则

1.1 BlindBox（以下简称“本平台”）是一款基于盲盒机制的线下社交陪伴体验信息撮合平台，运营主体为【公司全称】，注册地址为【越南注册地址】。

1.2 本协议是您与本平台之间就注册、使用本平台服务所订立的有效合约。您点击“同意”或实际使用本平台服务，即视为您已阅读、理解并同意接受本协议全部条款的约束。

1.3 本平台保留随时修改本协议的权利，修改后的协议将在App内公示。如您在协议修改后继续使用本平台服务，即视为您接受修改后的协议。

第二条 服务内容与平台定性

2.1 本平台提供的是信息撮合和技术服务，具体包括：盲盒匹配算法、用户身份验证、活动信息展示、支付通道对接、以及安全辅助工具。

2.2 本平台不直接提供、不参与、不担保任何线下陪伴服务本身。陪伴服务的合同关系存在于用户与服务提供者之间，平台不是该服务合同的当事人。

2.3 本平台收取的费用性质为信息中介服务费，而非陪伴服务费。

2.4 用户在使用本平台前，必须确认已年满18周岁，并已完成手机号实名认证（KYC）。

第三条 盲盒活动规则（碰运气促销合规）

3.1 本平台的盲盒属于越南法律规定的“碰运气促销”（chance-based promotional program）。根据规定，该活动已依法向越南工贸部（DOIT）或省级工贸厅完成注册。

3.2 用户支付固定金额后，随机获得不同级别的服务权益或场景体验（例如：额外服务时长、折扣权益、主题场景升级等）。随机性仅针对服务权益本身，绝不针对服务提供者的外貌、颜值或人格等级进行标价或分级。

3.3 中奖结果由系统随机算法生成，开盒过程支持在线见证与记录。每个独立促销活动的奖品总价值低于1亿越南盾时，可进行通知备案；达到1亿越南盾则须完成注册审批。

3.4 促销折扣不得超过促销前售价的50%。如未中奖，相关资金的处理将严格遵守越南促销法规。

3.5 本平台的中奖确定过程支持客户在线见证，系统自动记录开奖时间戳和结果日志，确保随机性透明可追溯。

第四条 线下见面安全规范

4.1 所有线下陪伴体验必须在本平台指定的公共咖啡馆或公共场所进行。严禁在私人空间（如酒店、公寓、私人会所、KTV包厢）进行见面。

4.2 严禁涉及任何形式的色情、涉黄、暴力、赌博行为。一经发现，平台将永久封禁账号，保存相关证据，并依法向越南公安机关举报。

4.3 根据越南法律，提供陪伴服务如被认定为涉及卖淫行为，将依据第282/2025/ND-CP号法令受到行政处罚，情节严重的可追究刑事责任。

4.4 平台建议用户：优先选择公共场合见面；避免进入密闭空间；必要时由朋友陪同；线上沟通时明确服务边界。

4.5 平台已启用“一键报警”和“紧急联系人”功能。开启后，盲盒匹配成功时系统将自动向您的紧急联系人分享实时位置，见面结束后自动停止共享。

4.6 本平台对用户线下见面过程中发生的纠纷、人身伤害或财产损失，不承担直接赔偿责任，但将协助提供必要的证据支持，并配合有关部门调查。

第五条 个人数据保护（PDPL合规）

5.1 本平台依据越南《个人数据保护法》（PDPL）及第356/2025/ND-CP号法令处理您的个人数据。

5.2 收集的数据类型：

  1. 基本个人数据：手机号码、姓名（可选）、出生日期（用于年龄验证）、电子邮箱。
  2. 敏感个人数据：个人位置数据（用于盲盒匹配和线下安全保障）、行为追踪数据（您在本平台上的社交网络使用行为，包括浏览记录、匹配偏好、互动历史等）。

5.3 数据收集目的：身份验证、盲盒匹配、线下安全保障、依法配合监管部门的调查、以及匿名化后的服务优化分析。

5.4 数据安全措施：敏感个人数据采用加密存储和传输、访问控制规则、数据匿名化处理等措施。电子身份账户的登录凭证（含身份证件图像）不包含在本平台的收集范围内。

5.5 安全事件通知：如发生涉及个人位置数据或生物识别数据的安全事件，本平台将在发现后72小时内同时向越南公安部及受影响用户发出通知。相关事件记录将在整改完成后至少保存五年。

5.6 同意机制：本平台采用明确的、可验证的同意机制。所有涉及敏感个人数据的处理，均需获得您的单独明示同意。本平台禁止默认同意、默示同意，或通过强制性、误导性设计获取同意。

5.7 数据共享：未经您的单独明示同意，本平台不会向第三方共享您的个人信息。在匹配成功后向匹配对象披露您的信息（如昵称、标签、模糊位置）之前，本平台将再次获取您的同意。

5.8 数据跨境传输：如涉及个人数据跨境传输，本平台将完成影响评估，并在60日内向越南公安部备案。

5.9 数据主体权利：您有权访问、更正、删除您的个人数据；有权撤回同意；有权要求限制处理。行使上述权利请联系【客服邮箱】。

6.1 用户不得利用本平台从事任何违反越南法律的行为，包括但不限于：诈骗、骚扰、传播违法信息、未经同意拍摄或传播他人影像。

6.2 用户不得在平台上发布虚假信息、使用虚假身份或冒用他人身份。

6.3 用户不得对服务提供者进行任何形式的性骚扰、肢体接触或言语侮辱。服务提供者有权在遭遇不适行为时立即终止服务，并报告平台。

6.4 本平台对所有注册会员实行实名认证，并对骚扰、不当行为和威胁行为实行零容忍政策。

6.5 用户违反本条款的，平台有权采取以下措施：警告、限制功能、暂停账号、永久封禁、扣除保证金、向公安机关举报。
