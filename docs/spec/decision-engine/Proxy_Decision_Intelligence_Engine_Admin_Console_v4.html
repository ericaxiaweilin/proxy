关键告警

这些问题比单纯模型 AUC 更危险
Exposure lineage missing ↑
一旦推荐产生的行为无法追溯来源，会直接污染后续兴趣/Intent。
Tag explosion without downstream lift
标签数量增长但没有任何区分度，要降级/归档，而不是继续堆。
Confidence high but coverage low
典型“模型过度自信”；强决策必须阻断。
Fulfillment ↑ but anger ↑
说明系统可能在“逼用户成交”，不能因为交易完成就判定成功。
System-induced evidence ratio ↑
推荐系统正在越来越依赖自己制造的数据。
Intervention saturation
主动触达频率高导致 usage drop / hide / mute 增加。

TTL Engineering

禁止为每个 UserTag 建独立 timer
UserTag { tag_id strength confidence last_seen expires_at decay_policy storage_tier } Read: if now > expires_at => inactive Cleanup: bucket sweeper archive / compact
Lazy Expire
读取时判断 expires_at，不依赖精确秒级 delete。
Bucket Sweeper
按小时/日分桶清理，减少 timer 数量和 write amplification。
Decay Instead of Rewrite
长期兴趣尽量用公式衰减，避免高频状态写入。
State Budget
监控 active/user、hot/user、memory/user、state-read p99。
