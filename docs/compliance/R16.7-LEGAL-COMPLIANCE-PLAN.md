- `apps/mobile/src/native-app.tsx`：
  - 新增 state `dateOfBirth: string` (YYYY-MM-DD, `>= 1900-01-01`)；
    `termsAccepted: boolean`; `privacyAccepted: boolean`。
  - 注册模式 UI（authMode === "register"）加 DOB `TextInput` + 两个
    `Pressable` checkbox（"我已阅读并同意 [服务使用协议] / [隐私政策]"）。
  - 当任一未勾选 / DOB 非法 → "获取验证码" 按钮 disabled。
  - 双链接 → `Linking.openURL` 打开 `docs/legal/Proxy_*_v1.1_Vietnam.md` 的
    公共 CDN URL（**TODO**：当前 mobile 不内置文档，需 server 提供
    `GET /v1/legal/terms` / `GET /v1/legal/privacy` 接口。

    `https://proxy.example/legal/terms` 即可；真实 URL 后续 P1 任务
    `R16.7-P1-A` 由 ops 在 server 端实现静态托管。
    **保守**做法：链接显示但点击提示"暂未上线"）。
  - 提交时 `loginClient.createAnonymousSession(platform, { dateOfBirth, consents: { terms: termsAccepted, privacy: privacyAccepted } })`。

- `apps/mobile/src/login-client.ts`：
  - `createAnonymousSession` 签名加 optional `consent` 参数；
  - payload 加 `dateOfBirth` + `consents` 字段；
  - `consents.terms` 或 `consents.privacy` 为 `false` → 抛
    `LoginProtocolError("terms and privacy consent required")`。

- `apps/mobile/src/login-client.test.ts`：
  - 新增 test 1：`createAnonymousSession` 时未传 `consents.terms` → 抛错。
  - 新增 test 2：`createAnonymousSession` 时 `dateOfBirth` 算 age < 18 → 抛错。

**后端 (api-go)**

- `apps/api-go/migrations/059_user_legal_consents.sql`：
  ```sql
  CREATE TABLE IF NOT EXISTS privacy.legal_consent_records (
      id           TEXT PRIMARY KEY,
      user_id      TEXT NOT NULL,
      doc_kind     TEXT NOT NULL,   -- 'TERMS' | 'PRIVACY'
      doc_version  TEXT NOT NULL,   -- '1.1'
      accepted_at  TIMESTAMPTZ NOT NULL,
      required     BOOLEAN NOT NULL,
      ip           INET,
      user_agent   TEXT,
      UNIQUE (user_id, doc_kind, doc_version)
  );
  CREATE INDEX IF NOT EXISTS idx_legal_consent_user
      ON privacy.legal_consent_records (user_id);
  ```
- `apps/api-go/internal/identity/service.go`：
  - `createAnonymousSessionPayload` 加 `DateOfBirth string` +
    `Consents struct { Terms, Privacy bool }`。
  - 校验：缺 `DateOfBirth` 或 `DateOfBirth` parse 失败 → `INVALID_ANONYMOUS_SESSION`。
  - 校验：age < 18 → `AGE_RESTRICTED` (新 error code)。
  - 校验：`!Consents.Terms || !Consents.Privacy` →
    `LEGAL_CONSENT_REQUIRED` (新 error code)。
  - 通过 → 在 `EnsureAnonymousIdentity` 成功后 `s.repository.RecordLegalConsent(ctx, user.ID, "TERMS", "1.1", ip, ua)` +
    `s.repository.RecordLegalConsent(ctx, user.ID, "PRIVACY", "1.1", ip, ua)`。
- `apps/api-go/internal/platform/postgres/identity.go`：
  - `IdentityRepository` interface 加 `RecordLegalConsent`。
  - `pgIdentityRepo` 实现。
- `apps/api-go/internal/identity/identity_integration_test.go`：
  - test 1: 缺 consents → `LEGAL_CONSENT_REQUIRED`。
  - test 2: `dateOfBirth="2020-01-01"` → `AGE_RESTRICTED`。
  - test 3: 全合法 → `legal_consent_records` 表多 2 行
    `(user_id, TERMS, 1.1, accepted_at)` + `(user_id, PRIVACY, 1.1, accepted_at)`。
