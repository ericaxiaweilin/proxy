# 用户浏览行为收集 —— 工程核查与待法务确认清单（2026-10-08）

工程事实，不是法律意见。依据：代码与开发库，核查日期 2026-10-08。

## 1. 收了什么
`localnet.interaction_events`（append-only）：POST_IMPRESSION、MEDIA_IMPRESSION、MEDIA_ZOOM、VIEW_END、PROFILE_OPEN、CANDIDATE_VIEWED、AGENT_SHORTLISTED。
字段：actor、目标类型/id、停留毫秒、时间。代码里把它归为敏感个人数据（Nghị định 356/2025 Art. 4.1(l)）。

## 2. 同意怎么拿（按目的分开，统一管线）
- 代码 `internal/consent` 是唯一登记处：每个目的有代码、政策版本、是否可授予。同意有效 = 事件发生时最近一次动作为 GRANT，且现在最近一次仍为 GRANT（`ValidAtSQL`）。
- 目的：`RECOMMENDATION`（推荐）、`TWIN_INSIGHT`（AI 分身好友洞察）、`OPERATOR_AUDIENCE_DETAIL`（运营/帖主逐人明细），政策版本 2026-10-08，均可授予；
  `AD_TARGETING` 已登记但**不提供**授予；`BEHAVIOR_ANALYTICS`（旧单开关）已退役，只能撤回，不再开启采集。
- App「设置与隐私」三个独立开关，**默认关**；服务端先写同意，成功才打开本地开关；读失败 = 不同意。至少一个采集目的开启才产生事件。
- 每个读取方只认自己的目的：引力/推荐、分身洞察、运营明细各自过滤，一个目的的同意不能代替另一个。
- `privacy.purpose_consents` 记录目的、政策版本、动作、时间、来源、ip、user agent；可撤回。

## 6. 标签层（TAG-SYSTEM-001，2026-10-08 新增）
标签是从行为派生出来的「这个人」的描述，供撮合 / 推荐读取。工程事实：
- **新增采集两项**：① `ACTIVITY_VIEW`（看某个活动页停留多久，和其它浏览事件同一条同意闸，已在端到端用例里）；
  ② 粗粒度位置 `RecordCoarseLocation`——服务端取整到约 1km 网格后只存格子 id，**不存原始经纬度**；
  要求「至少一个采集用途同意有效」**且**「定位同意（大致区域 / 精确）现在有效」，任何一道读不出来都拒收。
- **标签只来自两类事实**：用户主动做的事（点「感兴趣」/ 报名），和有同意的被动事件 / 位置。证据过滤用 `consent.ValidAtSQL`
  （事件那一刻同意有效且现在没撤回）。每小时全量重算；**撤回同意后下一轮重算就清掉**（重算会覆盖「已有标签的人」）。
- **读取要报用途**：每个标签轴声明 `allowed_use`，今天只开推荐 / 撮合 / 分析；`merchant_targeting`、`public` 一律不开。
- **账户删除**会连带删除该用户的标签和位置观测（回执里有计数）；窗口（28 天）外的位置观测由 worker 清掉。
- **撮合怎么用**：「共同兴趣」一项，出厂权重 0（上线不改任何人排名），运营在控制台打开才生效；没有标签的人这一项为 0，不扣分。

8. 「用户主动点感兴趣 / 报名」生成标签用于推荐，我们按「主动行为、不另需被动采集同意」处理；是否认可？
9. **账户删除目前不会删 `interaction_events`**（原始浏览事件，append-only，既有行为，不是本次引入）；标签已经会删。事件的删除 / 匿名化口径需要定。

### 6b. 细粒度标签（TAG-SYSTEM-002 / 003）
一个人的标签从「几个」扩到「几十个」：每个标签都有来源（被动行为 / 用户主动 / 混合）、强度、置信度、证据条数。
- **被动、要浏览同意**：场景兴趣 / 回避、内容话题（看过的帖子正文抽话题）、偏爱的创作者、活跃节律、常在城市、常去区域（粗粒度位置）。
- **用户主动、不需要浏览同意**：收藏 / 计划去 / 去过 / 打卡的店（及其类型、风格、所在区）、自己发的帖子里的话题、
  点过「感兴趣 / 报名」的活动、自己下过的单（服务类型、价位档、消费场景、时段）、接单资料里声明的服务能力与语种、完成过的服务。
- **话题词表是受控的**，且**刻意不含**夜生活 / 按摩 / KTV / 陪酒——平台不给用户贴这类标签再拿去推荐或撮合（见律师清单第 7 条）。
- **用户知情权**：`ListMyTags` 命令让用户看到自己的全部标签与画像（只能读自己）。App 里还没有入口，需要产品定放在哪里。
- 撮合用余弦相似度（稀疏向量，每一维都是一个可解释的标签），出厂权重仍为 0。

待法务确认（追加）：
11. 「用户主动」类标签（收藏的店、自己下的单、声明的能力）不另需浏览同意，是否认可？它们同样会进撮合与推荐。
12. 从自己发的公开帖子正文抽话题，是否算新的处理目的、是否要告知？
