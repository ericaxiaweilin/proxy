欢迎使用 Proxy。

本《Proxy 服务使用协议》（以下简称“本协议”）是你与 [Proxy Vietnam 法人全称]（以下简称“Proxy”“我们”）之间就使用 Proxy 产品及相关服务所订立的协议。

在创建账号、登录、点击“继续”、使用需要接受本协议的功能，或以其他明确方式接受本协议后，即表示你已经阅读、理解并同意本协议。

如果你不同意本协议，请停止使用相关服务。


1. 关于 Proxy

Proxy 是一项以通信、人与人连接及现实活动为基础的数字服务。

Proxy 可能提供包括但不限于：

- 账号注册和身份管理；
- 1:1 消息；
- 群聊；
- Convo 讨论；
- 语音和视频通话；
- 好友、关注及其他关系功能；
- 动态、图片、视频、评论和转发；
- 活动；
- 机会；
- 1:1 邀约；
- 商家页面；
- BUSINESS 身份；
- 订单；
- 礼品券、优惠券和权益；
- 第三方支付；
- 搜索、推荐和发现；
- 举报、安全及客服服务。

具体功能可能因地区、账号状态、设备或产品版本不同而有所差异。


2. 协议组成

本协议还包括 Proxy 根据具体功能发布的其他规则，包括：

- 《隐私政策及个人数据处理通知》；
- 《社区规范》；
- 《支付与交易规则》；
- 《BUSINESS / 商家规则》；
- 《现实互动与安全规则》；
- 具体活动、订单、券或其他服务页面显示的特别条件。

这些规则均构成本协议的一部分。

如果专项规则与本协议存在冲突，在该专项功能范围内，以专项规则为准，但越南法律另有强制规定的除外。


3. 使用资格

你必须具有越南法律要求的相应民事行为能力。

如果你属于未成年人或其他依法需要法定代表人同意的用户，某些功能可能需要：

- 法定代表人同意；
- 年龄确认；
- 身份验证；
- 功能限制；
- 更严格的隐私和安全保护。

Proxy 可以根据法律及风险等级限制未成年人使用支付、商业、位置、邀约或其他现实互动功能。


4. 注册账号

你可以通过 Proxy 支持的方式创建或访问账号，例如：

- Google；
- Email；
- Phone；
- Proxy 后续提供的其他身份验证方式。

登录方式与越南法律要求的账号验证可以是两个不同步骤。Google / Email 可以继续作为登录方式，但在越南法律要求的范围内，Proxy 将对数字账号进行必要的用户信息验证。

对于在越南提供服务的账号，Proxy 可以依法要求使用越南移动电话号码进行验证；用户没有越南移动电话号码时，可以依法使用个人识别号码或其他合法电子身份验证方式。

只有已经完成法律要求验证的账号，才能使用法律规定仅向已验证账号开放的发布、分享及互动功能。

如 Proxy 未来提供用于商业目的的 Livestream，相关账号还应按照适用法律完成更高等级的身份验证。

你应提供真实、有效和必要的信息。

不得：

- 批量注册虚假账号；
- 出售或出租账号；
- 冒用他人账号；
- 盗取账号；
- 使用自动化手段恶意注册；
- 使用账号实施诈骗或其他违法行为。


5. Google、Email 和 Phone 登录

使用 Google 登录时，身份验证由 Google 提供。

Proxy 不会获得你的 Google 密码。

使用 Email 或 Phone 时，Proxy 可以通过一次性验证码、设备验证、安全检查或其他合理方式确认身份。

手机号原则上属于私人账号信息，不因为注册 Proxy 而自动向其他用户公开。


6. 无账户模式

Proxy 可以允许用户在不创建正式账号的情况下体验部分功能。

在越南适用法律要求下，无账户模式原则上仅提供有限浏览和体验能力。未经法定账号验证的用户，不得使用依法仅向已验证账号开放的发布、分享及互动功能。

无账户模式可能无法使用：

- 发布动态、评论、转发或其他公开互动；
- 创建活动、机会或发送需要身份验证的邀约；
- 云端消息同步；
- 跨设备恢复；
- 完整好友关系；
- 订单；
- 礼品券；
- 支付；
- BUSINESS；
- 其他需要持续身份或法律验证的功能。

当用户进入需要身份确认、形成交易关系、持续保存数据或依法必须验证身份的功能时，Proxy 可以要求注册并完成相应验证。


7. 账号安全

你负责合理保护：

- 手机；
- Email；
- 验证码；
- 登录设备；
- 登录会话；
- 其他账号认证信息。

Proxy 不会要求你向其他普通用户提供验证码、银行卡密码或支付密码。

如果发现账号被盗或出现异常活动，应尽快通过 Proxy 客服或安全渠道联系我们。


8. Username、昵称和 Alias

Proxy 可以提供：

- Username；
- Display Name；
- 头像；
- Alias；
- 不同场景身份。

Alias 的目的主要是保护身份和控制不同关系中的信息暴露。

不得利用 Alias：

- 冒充其他真实个人；
- 冒充商家；
- 冒充政府机构；
- 冒充 Proxy 官方人员；
- 实施诈骗；
- 规避账号处罚。


9. 好友和关系

Proxy 可以提供：

- 添加好友；
- 关注；
- 联系人匹配；
- 共同群组；
- 共同活动；
- 曾共同参与；
- 其他关系状态。

Proxy 中的“好友”“关注”“共同参加过活动”等关系，仅代表平台内形成的关系。

这些状态不代表 Proxy 对某个人：

- 身份真实性；
- 信用；
- 专业能力；
- 现实安全；
- 履约能力

作出担保。


10. 通讯录

如果你主动授权 Proxy 访问通讯录，我们可以使用通讯录帮助你发现已使用 Proxy 的联系人。

Proxy 应尽可能采用必要且最小化的数据匹配方式。

你可以：

- 拒绝授权；
- 关闭通讯录权限；
- 停止同步；
- 根据产品功能请求删除已同步联系人数据。


11. 消息

Proxy 可以提供文字、图片、视频、语音、文件、位置、业务对象及其他形式的消息。

禁止通过消息：

- 诈骗；
- 威胁；
- 骚扰；
- 传播恶意软件；
- 大量发送垃圾信息；
- 推销违法商品；
- 传播法律禁止的内容；
- 索取他人的 OTP、密码或敏感支付信息。


12. 群聊

群组创建者和管理员可以依法及根据 Proxy 产品规则：

- 邀请或移除成员；
- 管理群组；
- 设置部分权限；
- 管理消息；
- 设置群组信息。

群组成员不得因为加入一个群组而自动获得其他私人空间或私人信息的访问权限。


13. Convo

Proxy 可以允许用户从某一条消息建立独立 Convo。

Convo 是围绕具体消息形成的讨论分支，并不等同于一个新的普通群组。

被加入 Convo 的外部用户，不因此自动成为原群组成员，也不会自动获得原群组全部历史内容的访问权限。


14. 语音及视频通话

Proxy 可以提供：

- 1:1 通话；
- 群组通话；
- 语音通话；
- 视频通话。

通话可能产生必要的技术数据，例如：

- 通话双方；
- 时间；
- 时长；
- 网络质量；
- 连接状态；
- 设备信息。


15. 通话录音

如果 Proxy 提供录音功能，普通通话和录音通话必须明确区分。

开始录音前应向参与者提供明显提示，并按照法律要求取得必要同意。

录音完成后，可以根据产品规则：

- 保存；
- 分享；
- 删除；
- 发送到聊天；
- 建立 Convo。


16. Secure Chat

Proxy 可以提供具有更高隐私保护级别的 Secure Chat。

具体可能包括：

- 端到端加密；
- 自毁消息；
- 限制保存；
- 安全媒体；
- 限制转发；
- 其他安全功能。

只有被明确标记为 Secure Chat 的通信才适用对应安全机制。

任何数字安全功能都不能完全阻止接收者利用其他设备拍摄或记录屏幕内容。


17. 动态

用户可以通过动态发布：

- 文字；
- 图片；
- 视频；
- 回复；
- Quote；
- Repost；
- @Mention；
- 其他允许内容。

用户应确保自己拥有发布相关内容所需的合法权利。


18. 用户内容所有权

你依法拥有的用户内容仍然属于你。

你不会因为将内容上传至 Proxy 而自动把内容所有权转让给 Proxy。

为了运行服务，你授权 Proxy 在必要范围内：

- 存储；
- 传输；
- 展示；
- 分发；
- 转码；
- 缓存；
- 备份；
- 进行安全和内容审核。

该授权仅用于提供、保护和改善 Proxy 服务以及履行法律义务。


19. 禁止内容

用户不得发布或传播：

- 越南法律禁止的内容；
- 儿童性剥削内容；
- 非自愿色情内容；
- 违法色情服务信息；
- 恐怖主义内容；
- 暴力威胁；
- 仇恨攻击；
- 诈骗；
- 恶意虚假身份；
- 侵犯知识产权的内容；
- 恶意暴露他人隐私；
- 非法商品或服务；
- 其他严重危害个人或社会安全的内容。


20. 搜索、发现和推荐

Proxy 可以依据：

- 用户明确选择；
- 用户关系；
- 内容相关性；
- 已授权位置；
- 时间；
- 活动上下文；
- 内容质量；
- 安全信号；
- 平台完整性信号

提供搜索、排序或推荐。

推荐并不意味着 Proxy 对某用户、商家、内容、活动或现实服务作保证。


21. 活动

“活动”是用户或商家创建的、允许多人参与的现实或线上活动。

活动创建者应提供真实且必要的信息，例如：

- 活动性质；
- 时间；
- 地点；
- 参与条件；
- 人数；
- 价格；
- 取消规则；
- 必要安全信息。

除非活动页面明确说明 Proxy 为活动实际组织者，否则 Proxy 通常仅提供技术、发现、报名和通信工具。


22. 机会

“机会”是用户或商家向不特定对象发布的开放需求。

发布者应明确：

- 需要什么；
- 时间；
- 地点；
- 条件；
- 服务范围；
- 价格或费用（如有）。

用户应自行判断是否响应。


23. 1:1 邀约

“邀约”是向已经选定的具体用户发送的定向行动请求。

Proxy 可以只允许白名单场景发送邀约，例如：

- 同行；
- 翻译；
- 拍照；
- 活动协助；
- 门店体验；
- 内容拍摄；
- 合法商务接待；
- 其他获得 Proxy 允许的场景。


24. 禁止的邀约

禁止通过 Proxy 邀约：

- 性服务；
- 色情交易；
- 付费亲密陪伴；
- 过夜陪伴；
- 以约会名义进行交易；
- 灰色陪伴服务；
- 非法赌博；
- 毒品；
- 人口贩运；
- 其他违法或高风险服务。

如果某项服务为付费服务，其价格必须对应：

具体场景 + 时间 + 地点 + 服务范围

而不能简单表现为“购买一个人”。


25. 好友与现实交友

Proxy 支持用户认识人、形成好友关系以及共同参与现实活动。

但 Proxy 并不是：

- 婚恋中介；
- 色情平台；
- 性服务平台；
- 有偿亲密陪伴平台。

用户应尊重其他人的边界和选择。

对方拒绝后，不得持续施压、骚扰或通过其他账号绕过屏蔽。


26. 现实互动安全

现实见面存在互联网平台无法完全消除的风险。

建议用户：

- 首次见面选择公共场所；
- 自己安排交通；
- 不轻易暴露家庭地址；
- 不轻易分享长期实时位置；
- 不向陌生人提供银行密码或 OTP；
- 在感到不安全时立即结束互动；
- 必要时联系警方或当地紧急服务。

Proxy 举报功能不能代替紧急救援。


27. BUSINESS 身份

符合条件的用户或组织可以使用 BUSINESS 身份。

BUSINESS 可以使用 Proxy 提供的商业工具，例如：

- 线上店铺；
- Creator 经营；
- 礼品券；
- 活动；
- 销售；
- 经营数据；
- 商家消息。


28. 商家信息

商家应保证其提供的信息：

- 真实；
- 准确；
- 完整；
- 不具有误导性。

包括：

- 企业或经营主体；
- 店铺名称；
- 地址；
- 商品；
- 服务；
- 价格；
- 许可证；
- 优惠；
- 礼品券；
- 联系方式。

需要行业资质的业务必须依法取得相应许可。


29. 市场

Proxy 市场可以帮助用户发现：

- 机会；
- 活动；
- 商家；
- 其他允许展示的业务对象。

如果 Proxy 的实际运营模式构成越南法律定义的电子商务平台、开展电子商务活动的社交网络、电子商务中介平台或其他受监管数字平台，Proxy 将按照实际功能而不是平台自我命名确定法律责任。

在适用情况下，Proxy 将依法履行：

- 平台登记或通知；
- 卖家/商家身份验证；
- 商品、服务和交易条件信息披露；
- 禁止商品、假冒商品及违法服务治理；
- 消费者投诉和争议处理；
- 交易、商家及平台运营数据保存；
- 与主管机关依法配合；
- 其他电子商务平台义务。

自相关电子身份验证要求依法适用之日起，商家、卖家及使用商业 Livestream 的主体还应完成适用的电子身份验证。


30. 订单

订单页面应尽可能明确：

- 交易主体；
- 商品或服务；
- 数量；
- 价格；
- 费用；
- 税费（如有）；
- 履约时间；
- 地点；
- 取消规则；
- 退款规则。

订单可以作为电子交易记录的一部分。


31. 礼品券和优惠券

券应明确显示：

- 发行主体；
- 面值或权益；
- 使用范围；
- 有效期；
- 限制条件；
- 是否允许转让；
- 是否允许退款；
- 其他重要条件。

禁止利用礼品券实施：

- 诈骗；
- 非法套现；
- 洗钱；
- 其他违法交易。


32. 支付

当前 Proxy 的支付设计原则是：

由银行或依法提供支付服务的第三方支付机构完成实际支付处理。

Proxy 本身不因为提供支付入口就自动成为：

- 银行；
- 电子钱包；
- 支付机构；
- 用户资金托管机构。

用户可能还需要接受实际支付服务提供商的相关条款。


33. 用户资金

除非未来 Proxy 获得相应法律资格并发布新的服务协议，否则 Proxy 不应：

- 自行发行电子钱包；
- 长期保存用户储值资金；
- 擅自进行 P2P 转账；
- 进行未经许可的资金托管；
- 提供依法需要支付许可的服务。

如果产品模式发生变化，将发布新的支付条款。


34. 退款及取消

具体退款和取消政策以：

- 对应订单；
- 活动；
- 商家；
- 券；
- 支付渠道；
- 法律规定

为准。

任何平台规则都不得取消越南法律赋予消费者的强制性权利。


35. 禁止商品及服务

禁止利用 Proxy 提供或促成包括但不限于：

- 非法毒品；
- 非法武器；
- 色情或性服务；
- 人口贩运；
- 非法赌博；
- 诈骗；
- 黑客服务；
- 伪造证件；
- 盗窃物品；
- 违法金融服务；
- 其他越南法律禁止的商品或服务。


36. 诈骗及账号欺诈

禁止：

- 恋爱诈骗；
- 投资诈骗；
- 工作诈骗；
- 假商家；
- 假客服；
- 礼品券诈骗；
- 支付诈骗；
- 骗取验证码；
- 冒充 Proxy；
- 其他欺骗行为。

Proxy 可以通过自动化风控和人工审核识别异常行为。


37. 内容审核

为了保护平台安全以及履行法律义务，Proxy 可以对内容或账号采取：

- 提醒；
- 降低传播；
- 限制发送消息；
- 删除内容；
- 暂停功能；
- 冻结交易；
- 暂停账号；
- 永久封禁。

处理措施将根据：

- 严重程度；
- 重复违规；
- 现实风险；
- 法律要求

- Refund ID；
- 必要风险数据。

原则上，完整银行卡认证数据应由实际支付机构处理。


22. 商家数据

BUSINESS 用户可能需要提供：

- 企业名称；
- 企业代码；
- 地址；
- 联系人；
- 许可证；
- 税务信息；
- 银行结算信息；
- 门店信息。

依法要求向消费者公开的信息可以展示在商家页面。


23. 使用数据的目的

Proxy 主要为了：

- 创建账号；
- 身份验证；
- 保护账号；
- 提供消息；
- 提供群聊；
- 提供好友关系；
- 提供动态；
- 提供活动；
- 提供机会；
- 提供邀约；
- 提供商家服务；
- 处理订单；
- 处理支付状态；
- 防止诈骗；
- 内容安全；
- 客服；
- 处理投诉；
- 改善产品可靠性；
- 履行法律义务

处理数据。


24. 同意

当法律要求用户同意时，Proxy 应以：

- 清楚；
- 具体；
- 可理解；
- 可证明

的方式取得同意。

不得单纯以：

- 沉默；
- 预先勾选；
- 模糊行为

替代法律要求的有效同意。

对于不同处理目的，Proxy 应尽可能提供分目的、可管理的授权和撤回机制，而不是把与核心服务无直接必要关系的数据处理全部捆绑在注册动作中。

例如：

- 通讯录访问；
- 精确位置；
- 非必要 Cookie；
- 跨场景跟踪；
- 营销；
- 通话录音；
- 其他依法要求独立选择的处理

应在相应功能发生时提供适当说明和控制。


25. 撤回同意

如果某项数据处理依赖你的同意，你可以依法撤回该同意。

撤回同意不会使撤回前合法完成的数据处理自动变成违法。

如果某项数据是提供服务所必需的，撤回后相应功能可能无法继续运行。


26. 法律允许的非同意处理

越南法律在特定情况下可能允许不依赖用户同意处理数据，例如：

- 保护生命或健康的紧急情况；
- 履行法定义务；
- 依法响应有权国家机关；
- 法律规定的其他情况。

Proxy 只会在法律允许范围内使用这些例外。


27. 数据共享

Proxy 不会出售用户个人数据。

在以下必要情况下，Proxy 可以共享数据：

- 用户主动要求；
- 完成订单；
- 支付；
- 商家履约；
- 云计算；
- SMS；
- Email；
- Google 登录；
- 客服；
- 安全；
- 反欺诈；
- 法律义务。


28. 服务提供商

Proxy 可能使用外部服务提供商，例如：

- Cloud；
- CDN；
- Google Identity；
- SMS；
- Email；
- Payment；
- Analytics；
- Customer Support；
- Security。

Proxy 应仅允许这些服务商为了约定目的处理必要数据。


29. 第三方不得自行利用数据

服务提供商不得因为为 Proxy 提供技术服务，就擅自把 Proxy 用户数据用于与约定服务无关的用途。

Proxy 应通过：

- 合同；
- 权限；
- 技术控制；
- 安全要求

管理处理方。


30. 跨境数据传输

Proxy 可能使用全球技术和云服务，因此越南用户个人数据可能在越南境外进行处理。

如果发生跨境个人数据传输，Proxy 将按照越南适用法律建立、维护和提交必要的跨境数据处理文件和影响评估。


31. 数据保存

Proxy 不应无限期保存所有数据。

数据保存期限根据：

- 服务目的；
- 账号状态；
- 用户选择；
- 安全需要；
- 交易；
- 投诉；
- 税务；
- 法定保存要求

确定。

当数据不再需要时，应依法：

- 删除；
- 匿名化；
- 或采用其他允许的处理方式。


32. 账号删除

用户应可以请求注销 Proxy 账号。

账号注销后，应删除不再需要的个人数据。

但以下数据可能需要继续保存：

- 财务记录；
- 交易凭证；
- 税务资料；
- 欺诈证据；
- 投诉记录；
- 法律争议；
- 监管要求保存的信息。


33. 用户访问权

根据适用法律，你可以请求了解 Proxy 正在处理与你有关的个人数据。


34. 更正权

如果个人数据不准确，你可以要求更正。


35. 删除权

在法律规定的条件下，你可以请求删除个人数据。


36. 限制处理

在适用情况下，你可以要求限制某些个人数据处理。


37. 反对处理

在法律规定的范围内，你可以反对特定数据处理活动。


38. 数据提供

在适用情况下，你可以请求 Proxy 按法律要求向你提供自己的个人数据。


39. 投诉权

如果认为个人数据权利受到侵害，可以：

- 联系 Proxy；
- 提交投诉；
- 向有权主管机关反映；
- 依法采取其他救济措施。


40. 儿童数据

Proxy 对儿童数据实施额外保护。

涉及法律要求的儿童数据处理时，应依法取得：

- 儿童本人适当意思表示；
- 法定代表人同意；
- 或其他法律要求的授权。

不得将儿童数据用于违法剥削、诱导或其他有害目的。


41. AI 和自动化处理

Proxy 可以使用算法或 AI 用于：

- 搜索；
- 排序；
- 内容理解；
- 垃圾信息检测；
- 欺诈检测；
- 推荐；
- 平台安全；
- 产品辅助。

涉及依法需要额外通知、同意或人工复核的重要自动化决定时，将采取相应保护措施。


42. 营销

如果 Proxy 向用户发送营销消息，应遵守越南关于：

- 广告；
- 反垃圾信息；
- 个人数据；
- 消费者保护

的适用要求。

用户应能够关闭依法允许退出的营销通信。


43. Cookie 与“Do Not Track”选择

Web 版本可以使用必要 Cookie 维持：

- 登录；
- 安全；
- 会话；
- 语言；
- 基础功能。

对于社交网络和在线通信服务，Proxy 应向用户提供适用的 Cookie 拒绝选择。

对于依法需要额外同意的非必要 Cookie，应提供相应选择。

Proxy 还应提供适用的“不跟踪（Do Not Track）”选择，或仅在用户同意的情况下跟踪其使用社交网络、在线通信服务的活动。


44. 数据安全

Proxy 将根据风险采用合理安全措施，例如：

- 加密传输；
- 身份验证；
- 最小权限；
- Access Control；
- 日志；
- 安全监控；
- 密钥管理；
- 漏洞修复；
- 备份；
- 员工权限管理。

任何互联网系统都无法承诺绝对不存在风险。


45. 数据泄露及安全事件

发生个人数据安全事件时，Proxy 将：

1. 调查事件；
2. 控制风险；
3. 保存必要证据；
4. 评估影响；
5. 采取补救措施；
6. 在达到法定条件时向主管机关报告；
7. 在法律要求时通知受影响用户。


46. 数据处理影响评估

Proxy 将根据越南适用的个人数据保护要求，对个人数据处理建立必要的：

Data Protection Impact Assessment / 数据处理影响评估文件。

评估内容可包括：

- 数据类型；
- 数据主体；
- 处理目的；
- 数据流程；
- 处理方；
- 保存；
- 删除；
- 安全措施；
- 风险；
- 缓解措施。


47. 跨境数据影响评估

如果越南用户个人数据发生法律意义上的跨境传输，Proxy 将建立相应：

Cross-border Data Transfer Impact Assessment。

并依法维护、更新及办理必要程序。


48. Privacy Settings

Proxy 应逐步提供包括：

- 手机号发现；
- 通讯录同步；
- 在线状态；
- 好友权限；
- 位置；
- 消息请求；
- Mặc Kệ；
- Alias；
- 群组权限；
- Secure Chat；
- 营销设置；
- 账号删除

等隐私控制。


49. 政策更新

如果：

- 新增重要数据类别；
- 新增处理目的；
- 新增重大业务；
- 改变跨境路径；
- 法律发生变化；

Proxy 可以更新本政策。

对于法律要求重新取得用户同意的变化，将重新请求相应同意。

51. 账号验证数据

为履行越南网络安全和数字账号验证义务，Proxy 可以处理：

- 越南移动电话号码；
- 账号验证状态；
- 个人识别号码（仅在法律允许且必要时）；
- 合法电子身份验证结果；
- 验证时间、方式及必要审计记录。

上述数据仅用于身份验证、安全、法律合规及其他明确告知的合法目的。

完成验证不意味着 Proxy 可以把手机号、个人识别号码或其他验证数据公开给好友、群组成员、活动参与者或其他普通用户。


52. 社交网络和在线通信特别隐私规则

对于 Proxy 的社交网络和在线通信功能，我们应：

- 清楚说明安装和使用服务时收集哪些个人数据；
- 不超出已告知或合法范围收集数据；
- 为 Cookie 提供适用的拒绝选择；
- 提供“不跟踪”选择，或在取得用户同意后再跟踪相关使用活动；
- 不在没有用户同意或其他明确法律依据的情况下监听、录制通话或读取消息内容；
- 提供访问、更正、删除和隐私设置机制；
- 提供隐私和安全违规举报渠道；
- 对越南用户个人数据的跨境处理实施相应保护。

当法律依法授权有权机关访问或要求提供相关数据时，Proxy 将按照合法请求机制处理。


53. 系统日志保存

为了履行越南网络安全义务，Proxy 可以保存必要系统日志，包括：

- 用户账号；
- 登录和退出时间；
- IP；
- 登录和退出时的源端口；
- 已发布信息处理日志；
- 安全事件及账号处置记录。

适用网络安全日志应至少保持 12 个月可检索能力，法律要求更长时间的除外。

该日志保存属于平台安全和法律合规目的，不代表 Proxy 可以把日志用于与上述目的无关的营销或个人画像。


54. 合法政府请求

Proxy 仅在收到具有法律依据且来自有权机关的有效请求时，依法提供必要用户信息或执行相关网络安全措施。

Proxy 将建立请求验证、最小化披露、访问控制、内部审批和处理日志机制。

在适用网络安全规则要求下，Proxy 应具备满足一般 24 小时及特定紧急情形 3 小时的信息响应能力，以及违法信息处置的一般 24 小时和国家安全紧急情形 6 小时响应能力。


55. 数据处理影响评估与更新

Proxy 将依据越南《个人数据保护法》及其实施规定建立个人数据处理影响评估文件。

当处理活动、组织结构、数据类别、处理目的、技术架构、处理方或其他法定事项发生变化时，应按照适用法律更新影响评估。

相关影响评估文件还应按照现行规则进行定期审查和必要更新。


56. 跨境数据影响评估

如果越南用户个人数据发生法律意义上的跨境传输，Proxy 将：

- 识别数据接收方和传输路径；
- 记录传输目的、数据类型和保护措施；
- 建立跨境个人数据传输影响评估文件；
- 按越南法律要求提交、维护和更新；
- 对云服务、AI 服务、CDN、支付、分析及其他境外处理方进行相应评估。


57. 电子商务和商家数据

当 Proxy 构成越南法律定义的开展电子商务活动的社交网络、电子商务平台或其他受监管平台时，我们可能依法处理和保存：

- 商家身份验证数据；
- 企业或经营主体信息；
- 商品及服务信息；
- 订单和交易记录；
- 消费者投诉；
- 平台处置记录；
- 税务、发票或依法要求提供的数据。

这些数据只在交易履行、消费者保护、税务、平台治理、安全和法律义务所需要的范围内处理。

本中文稿截至 2026-08-31，根据 Proxy 当前功能并结合越南现行个人数据、网络安全、电子商务、消费者保护、电子交易及相关法律制度更新。

重点法律框架包括：

- 《个人数据保护法》91/2025/QH15；
- 356/2025/NĐ-CP；
