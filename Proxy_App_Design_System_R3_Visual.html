把品牌 Logo、字体、字号、模块 Icon、尺寸、形状、颜色、导航、交互和文案全部锁成可执行规则。后续任何原型都从这套 registry 取值，不再临时发挥。

01 · Brand Assets

正式品牌 Logo

Header 32px · Row 44px · Proxy Center 56px

禁止
不要再套彩色底，不要裁脸，不要用启动轮廓水獭代替正式 Logo。

06 · Module Card Geometry

2-column first-level module

Card = square · radius 24 · icon box 56/r16 · name 15/21/800 · status 11/15/600 · all centered.

Wide row

Height 72–80 · icon/logo 44–56 · text left · chevron right. 只用于 Proxy Center、身份/品牌类入口。

07 · Composer

只有相机/图片、语音、发送。无水獭，无渐变，无红色。

08 · Interaction / UX Gate

一级卡整卡可点，不塞“查看”。
重要数字/来源/状态必须穿透。
二级页第一屏显示真实对象，不再出现功能空壳。
Bottom Nav：Home / Market / Feed / Chat / Me。
消息 icon 固定 chat bubble，禁止 envelope。
身份切换只在「我的」底部。
按压只变 Soft 背景，禁止 hover 浮起。
所有卡片 0 阴影。
正文 ≥11px；Body 推荐 14px。
