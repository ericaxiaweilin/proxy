欢迎使用 Proxy。

本《Proxy 服务使用协议》（以下简称“本协议”）是你与 [Proxy Vietnam 法人全称]（以下简称“Proxy”“我们”）之间就使用 Proxy 产品及相关服务所订立的协议。

在创建账号、登录、点击“继续”、使用需要接受本协议的功能，或以其他明确方式接受本协议后，即表示你已经阅读、理解并同意本协议。

如果你不同意本协议，请停止使用相关服务。


1. 关于 Proxy

Proxy 是一项以通信、人与人连接及现实活动为基础的数字服务。

Proxy 可能提供包括但不限于：

- 账号注册和身份管理；
- 1:1 消息；
- 群聊；
- Convo 讨论；
- 语音和视频通话；
- 好友、关注及其他关系功能；
- 动态、图片、视频、评论和转发；
- 活动；
- 机会；
- 1:1 邀约；
- 商家页面；
- BUSINESS 身份；
- 订单；
- 礼品券、优惠券和权益；
- 第三方支付；
- 搜索、推荐和发现；
- 举报、安全及客服服务。

具体功能可能因地区、账号状态、设备或产品版本不同而有所差异。


2. 协议组成

本协议还包括 Proxy 根据具体功能发布的其他规则，包括：

- 《隐私政策及个人数据处理通知》；
- 《社区规范》；
- 《支付与交易规则》；
- 《BUSINESS / 商家规则》；
- 《现实互动与安全规则》；
- 具体活动、订单、券或其他服务页面显示的特别条件。

这些规则均构成本协议的一部分。

如果专项规则与本协议存在冲突，在该专项功能范围内，以专项规则为准，但越南法律另有强制规定的除外。


3. 使用资格

你必须具有越南法律要求的相应民事行为能力。

如果你属于未成年人或其他依法需要法定代表人同意的用户，某些功能可能需要：

- 法定代表人同意；
- 年龄确认；
- 身份验证；
- 功能限制；
- 更严格的隐私和安全保护。

Proxy 可以根据法律及风险等级限制未成年人使用支付、商业、位置、邀约或其他现实互动功能。


4. 注册账号

你可以通过 Proxy 支持的方式创建或访问账号，例如：

- Google；
- Email；
- Phone；
- Proxy 后续提供的其他身份验证方式。

登录方式与越南法律要求的账号验证可以是两个不同步骤。Google / Email 可以继续作为登录方式，但在越南法律要求的范围内，Proxy 将对数字账号进行必要的用户信息验证。

对于在越南提供服务的账号，Proxy 可以依法要求使用越南移动电话号码进行验证；用户没有越南移动电话号码时，可以依法使用个人识别号码或其他合法电子身份验证方式。

只有已经完成法律要求验证的账号，才能使用法律规定仅向已验证账号开放的发布、分享及互动功能。

如 Proxy 未来提供用于商业目的的 Livestream，相关账号还应按照适用法律完成更高等级的身份验证。

你应提供真实、有效和必要的信息。

不得：

- 批量注册虚假账号；
- 出售或出租账号；
- 冒用他人账号；
- 盗取账号；
- 使用自动化手段恶意注册；
- 使用账号实施诈骗或其他违法行为。


5. Google、Email 和 Phone 登录

使用 Google 登录时，身份验证由 Google 提供。

Proxy 不会获得你的 Google 密码。

使用 Email 或 Phone 时，Proxy 可以通过一次性验证码、设备验证、安全检查或其他合理方式确认身份。

手机号原则上属于私人账号信息，不因为注册 Proxy 而自动向其他用户公开。


6. 无账户模式

Proxy 可以允许用户在不创建正式账号的情况下体验部分功能。

在越南适用法律要求下，无账户模式原则上仅提供有限浏览和体验能力。未经法定账号验证的用户，不得使用依法仅向已验证账号开放的发布、分享及互动功能。

无账户模式可能无法使用：

- 发布动态、评论、转发或其他公开互动；
- 创建活动、机会或发送需要身份验证的邀约；
- 云端消息同步；
- 跨设备恢复；
- 完整好友关系；
- 订单；
- 礼品券；
- 支付；
- BUSINESS；
- 其他需要持续身份或法律验证的功能。

当用户进入需要身份确认、形成交易关系、持续保存数据或依法必须验证身份的功能时，Proxy 可以要求注册并完成相应验证。


7. 账号安全

你负责合理保护：

- 手机；
- Email；
- 验证码；
- 登录设备；
- 登录会话；
- 其他账号认证信息。

Proxy 不会要求你向其他普通用户提供验证码、银行卡密码或支付密码。

如果发现账号被盗或出现异常活动，应尽快通过 Proxy 客服或安全渠道联系我们。


8. Username、昵称和 Alias

Proxy 可以提供：

- Username；
- Display Name；
- 头像；
- Alias；
- 不同场景身份。

Alias 的目的主要是保护身份和控制不同关系中的信息暴露。

不得利用 Alias：

- 冒充其他真实个人；
- 冒充商家；
- 冒充政府机构；
- 冒充 Proxy 官方人员；
- 实施诈骗；
- 规避账号处罚。


9. 好友和关系

Proxy 可以提供：

- 添加好友；
- 关注；
- 联系人匹配；
- 共同群组；
- 共同活动；
- 曾共同参与；
- 其他关系状态。

Proxy 中的“好友”“关注”“共同参加过活动”等关系，仅代表平台内形成的关系。

这些状态不代表 Proxy 对某个人：

- 身份真实性；
- 信用；
- 专业能力；
- 现实安全；
- 履约能力

作出担保。


10. 通讯录

如果你主动授权 Proxy 访问通讯录，我们可以使用通讯录帮助你发现已使用 Proxy 的联系人。

Proxy 应尽可能采用必要且最小化的数据匹配方式。

你可以：

- 拒绝授权；
- 关闭通讯录权限；
- 停止同步；
- 根据产品功能请求删除已同步联系人数据。


11. 消息

Proxy 可以提供文字、图片、视频、语音、文件、位置、业务对象及其他形式的消息。

禁止通过消息：

- 诈骗；
- 威胁；
- 骚扰；
- 传播恶意软件；
- 大量发送垃圾信息；
- 推销违法商品；
- 传播法律禁止的内容；
- 索取他人的 OTP、密码或敏感支付信息。


12. 群聊

群组创建者和管理员可以依法及根据 Proxy 产品规则：

- 邀请或移除成员；
- 管理群组；
- 设置部分权限；
- 管理消息；
- 设置群组信息。

群组成员不得因为加入一个群组而自动获得其他私人空间或私人信息的访问权限。


13. Convo

Proxy 可以允许用户从某一条消息建立独立 Convo。

Convo 是围绕具体消息形成的讨论分支，并不等同于一个新的普通群组。

被加入 Convo 的外部用户，不因此自动成为原群组成员，也不会自动获得原群组全部历史内容的访问权限。


14. 语音及视频通话

Proxy 可以提供：

- 1:1 通话；
- 群组通话；
- 语音通话；
- 视频通话。

通话可能产生必要的技术数据，例如：

- 通话双方；
- 时间；
- 时长；
- 网络质量；
- 连接状态；
- 设备信息。


15. 通话录音

如果 Proxy 提供录音功能，普通通话和录音通话必须明确区分。

开始录音前应向参与者提供明显提示，并按照法律要求取得必要同意。

录音完成后，可以根据产品规则：

- 保存；
- 分享；
- 删除；
- 发送到聊天；
- 建立 Convo。


16. Secure Chat

Proxy 可以提供具有更高隐私保护级别的 Secure Chat。

具体可能包括：

- 端到端加密；
- 自毁消息；
- 限制保存；
- 安全媒体；
- 限制转发；
- 其他安全功能。

只有被明确标记为 Secure Chat 的通信才适用对应安全机制。

任何数字安全功能都不能完全阻止接收者利用其他设备拍摄或记录屏幕内容。


17. 动态

用户可以通过动态发布：

- 文字；
- 图片；
- 视频；
- 回复；
- Quote；
- Repost；
- @Mention；
- 其他允许内容。

用户应确保自己拥有发布相关内容所需的合法权利。


18. 用户内容所有权

你依法拥有的用户内容仍然属于你。

你不会因为将内容上传至 Proxy 而自动把内容所有权转让给 Proxy。

为了运行服务，你授权 Proxy 在必要范围内：

- 存储；
- 传输；
- 展示；
- 分发；
- 转码；
- 缓存；
- 备份；
- 进行安全和内容审核。

该授权仅用于提供、保护和改善 Proxy 服务以及履行法律义务。


19. 禁止内容

用户不得发布或传播：

- 越南法律禁止的内容；
- 儿童性剥削内容；
- 非自愿色情内容；
- 违法色情服务信息；
- 恐怖主义内容；
- 暴力威胁；
- 仇恨攻击；
- 诈骗；
- 恶意虚假身份；
- 侵犯知识产权的内容；
- 恶意暴露他人隐私；
- 非法商品或服务；
- 其他严重危害个人或社会安全的内容。


20. 搜索、发现和推荐

Proxy 可以依据：

- 用户明确选择；
- 用户关系；
- 内容相关性；
- 已授权位置；
- 时间；
- 活动上下文；
- 内容质量；
- 安全信号；
- 平台完整性信号

提供搜索、排序或推荐。

推荐并不意味着 Proxy 对某用户、商家、内容、活动或现实服务作保证。


21. 活动

“活动”是用户或商家创建的、允许多人参与的现实或线上活动。

活动创建者应提供真实且必要的信息，例如：

- 活动性质；
- 时间；
- 地点；
- 参与条件；
- 人数；
- 价格；
- 取消规则；
- 必要安全信息。

除非活动页面明确说明 Proxy 为活动实际组织者，否则 Proxy 通常仅提供技术、发现、报名和通信工具。


22. 机会

“机会”是用户或商家向不特定对象发布的开放需求。

发布者应明确：

- 需要什么；
- 时间；
- 地点；
- 条件；
- 服务范围；
- 价格或费用（如有）。

用户应自行判断是否响应。


23. 1:1 邀约

“邀约”是向已经选定的具体用户发送的定向行动请求。

Proxy 可以只允许白名单场景发送邀约，例如：

- 同行；
- 翻译；
- 拍照；
- 活动协助；
- 门店体验；
- 内容拍摄；
- 合法商务接待；
- 其他获得 Proxy 允许的场景。


24. 禁止的邀约

禁止通过 Proxy 邀约：

- 性服务；
- 色情交易；
- 付费亲密陪伴；
- 过夜陪伴；
- 以约会名义进行交易；
- 灰色陪伴服务；
- 非法赌博；
- 毒品；
- 人口贩运；
- 其他违法或高风险服务。

如果某项服务为付费服务，其价格必须对应：

具体场景 + 时间 + 地点 + 服务范围

而不能简单表现为“购买一个人”。


25. 好友与现实交友

Proxy 支持用户认识人、形成好友关系以及共同参与现实活动。

但 Proxy 并不是：

- 婚恋中介；
- 色情平台；
- 性服务平台；
- 有偿亲密陪伴平台。

用户应尊重其他人的边界和选择。

对方拒绝后，不得持续施压、骚扰或通过其他账号绕过屏蔽。


26. 现实互动安全

现实见面存在互联网平台无法完全消除的风险。

建议用户：

- 首次见面选择公共场所；
- 自己安排交通；
- 不轻易暴露家庭地址；
- 不轻易分享长期实时位置；
- 不向陌生人提供银行密码或 OTP；
- 在感到不安全时立即结束互动；
- 必要时联系警方或当地紧急服务。

Proxy 举报功能不能代替紧急救援。


27. BUSINESS 身份

符合条件的用户或组织可以使用 BUSINESS 身份。

BUSINESS 可以使用 Proxy 提供的商业工具，例如：

- 线上店铺；
- Creator 经营；
- 礼品券；
- 活动；
- 销售；
- 经营数据；
- 商家消息。


28. 商家信息

商家应保证其提供的信息：

- 真实；
- 准确；
- 完整；
- 不具有误导性。

包括：

- 企业或经营主体；
- 店铺名称；
- 地址；
- 商品；
- 服务；
- 价格；
- 许可证；
- 优惠；
- 礼品券；
- 联系方式。

需要行业资质的业务必须依法取得相应许可。


29. 市场

Proxy 市场可以帮助用户发现：

- 机会；
- 活动；
- 商家；
- 其他允许展示的业务对象。

如果 Proxy 的实际运营模式构成越南法律定义的电子商务平台、开展电子商务活动的社交网络、电子商务中介平台或其他受监管数字平台，Proxy 将按照实际功能而不是平台自我命名确定法律责任。

在适用情况下，Proxy 将依法履行：

- 平台登记或通知；
- 卖家/商家身份验证；
- 商品、服务和交易条件信息披露；
- 禁止商品、假冒商品及违法服务治理；
- 消费者投诉和争议处理；
- 交易、商家及平台运营数据保存；
- 与主管机关依法配合；
- 其他电子商务平台义务。

自相关电子身份验证要求依法适用之日起，商家、卖家及使用商业 Livestream 的主体还应完成适用的电子身份验证。


30. 订单

订单页面应尽可能明确：

- 交易主体；
- 商品或服务；
- 数量；
- 价格；
- 费用；
- 税费（如有）；
- 履约时间；
- 地点；
- 取消规则；
- 退款规则。

订单可以作为电子交易记录的一部分。


31. 礼品券和优惠券

券应明确显示：

- 发行主体；
- 面值或权益；
- 使用范围；
- 有效期；
- 限制条件；
- 是否允许转让；
- 是否允许退款；
- 其他重要条件。

禁止利用礼品券实施：

- 诈骗；
- 非法套现；
- 洗钱；
- 其他违法交易。


32. 支付

当前 Proxy 的支付设计原则是：

由银行或依法提供支付服务的第三方支付机构完成实际支付处理。

Proxy 本身不因为提供支付入口就自动成为：

- 银行；
- 电子钱包；
- 支付机构；
- 用户资金托管机构。

用户可能还需要接受实际支付服务提供商的相关条款。


33. 用户资金

除非未来 Proxy 获得相应法律资格并发布新的服务协议，否则 Proxy 不应：

- 自行发行电子钱包；
- 长期保存用户储值资金；
- 擅自进行 P2P 转账；
- 进行未经许可的资金托管；
- 提供依法需要支付许可的服务。

如果产品模式发生变化，将发布新的支付条款。


34. 退款及取消

具体退款和取消政策以：

- 对应订单；
- 活动；
- 商家；
- 券；
- 支付渠道；
- 法律规定

为准。

任何平台规则都不得取消越南法律赋予消费者的强制性权利。


35. 禁止商品及服务

禁止利用 Proxy 提供或促成包括但不限于：

- 非法毒品；
- 非法武器；
- 色情或性服务；
- 人口贩运；
- 非法赌博；
- 诈骗；
- 黑客服务；
- 伪造证件；
- 盗窃物品；
- 违法金融服务；
- 其他越南法律禁止的商品或服务。


36. 诈骗及账号欺诈

禁止：

- 恋爱诈骗；
- 投资诈骗；
- 工作诈骗；
- 假商家；
- 假客服；
- 礼品券诈骗；
- 支付诈骗；
- 骗取验证码；
- 冒充 Proxy；
- 其他欺骗行为。

Proxy 可以通过自动化风控和人工审核识别异常行为。


37. 内容审核

为了保护平台安全以及履行法律义务，Proxy 可以对内容或账号采取：

- 提醒；
- 降低传播；
- 限制发送消息；
- 删除内容；
- 暂停功能；
- 冻结交易；
- 暂停账号；
- 永久封禁。

处理措施将根据：

- 严重程度；
- 重复违规；
- 现实风险；
- 法律要求

综合决定。

针对网络安全主管机关依法提出的有效用户信息请求，Proxy 将建立能够满足法定响应时限的流程。

截至本版本更新日，适用规则包括：

- 一般有效用户信息请求：最迟 24 小时内处理；
- 涉及国家安全或生命安全的紧急有效请求：最迟 3 小时内处理；
- 依法要求限制访问、删除违法信息或移除违法服务：最迟 24 小时内处理；
- 国家安全紧急情况下的相关内容处置：最迟 6 小时内处理。

所有请求应进行主体、权限、范围和合法性核验，并对处理过程进行记录。
