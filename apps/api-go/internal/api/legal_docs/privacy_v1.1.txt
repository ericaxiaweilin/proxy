收集什么 → 为什么收集 → 如何使用 → 与谁共享 → 保存多久 → 如何保护 → 用户有什么权利。

4. 敏感个人数据

根据越南法律，某些数据可能属于敏感个人数据。

例如在特定情况下：

- 金融信息；
- 精确位置；
- 儿童数据；
- 身份相关信息；
- 法律定义的其他敏感个人数据。

对于敏感个人数据，Proxy 将采用更严格的：

- 权限；
- 安全；
- 记录；
- 处理；
- 法律合规措施。


5. 我们不会无目的收集数据

Proxy 应遵循数据最小化原则。

如果某个功能不需要：

- 身份证；
- 精确位置；
- 通讯录；
- 金融数据；
- 其他敏感信息，

Proxy 不应为了“以后可能有用”而无目的收集。


6. 数据来源

数据可能来自：

1. 你主动提供；
2. 你使用 Proxy 时自动产生；
3. 你授权的设备权限；
4. Google 或其他身份服务；
5. 支付机构；
6. 与订单有关的商家；
7. 依法允许的其他来源。


7. Google 登录

如果你使用 Google 登录，Proxy 可以获得 Google 在你授权范围内提供的信息，例如：

- Google 账号标识；
- Email；
- 名称；
- 头像。

Proxy 不会获得你的 Google 密码。

Google 登录属于账号认证方式之一，并不当然替代越南法律要求的数字账号身份验证。当法律要求时，Proxy 还会要求完成越南移动电话号码、个人识别号码或其他合法电子身份验证。


8. Phone 和 Email

Proxy 可以使用 Phone 或 Email：

- 登录；
- 注册；
- 验证；
- 安全提醒；
- 账号恢复；
- 法律要求的通知。

在越南法律要求的范围内，Proxy 可以使用越南移动电话号码完成数字账号验证；没有越南移动电话号码的用户，可以依法使用个人识别号码或其他合法电子身份验证方式。

手机号默认不作为公开资料显示。

对于社交网络和在线通信账号验证，Proxy 原则上不把要求用户上传包含完整或部分身份证件内容的图片、视频作为常规账号验证要素；需要更高等级身份确认时，应优先使用法律允许的电子身份验证机制。


9. 无账户用户

即使使用无账户模式，为了：

- 维持会话；
- 安全；
- 防止攻击；
- 保存用户主动进行的操作；

Proxy 仍可能处理有限设备和技术数据。

无账户模式的数据范围应明显少于完整账号模式。


10. 通讯录

只有获得设备权限后，Proxy 才访问通讯录。

通讯录主要用于：

- 联系人匹配；
- 好友发现；
- 用户明确要求的社交功能。

用户可以随时关闭系统通讯录权限。


11. 消息

普通消息可能为了：

- 投递；
- 同步；
- 多设备访问；
- 搜索；
- 用户备份；
- 举报；
- 安全处理

存储于 Proxy 的服务器系统。

仅有权访问相应 Dialog、Group 或 Convo 的用户才能正常访问内容。


12. Secure Chat

如果 Proxy 明确标记某会话为端到端加密 Secure Chat，则应按照该产品承诺设计：

- 密钥管理；
- 消息存储；
- 解密权限；
- 安全媒体。

Proxy 服务器不应在声称“端到端加密”的情况下同时保存能够正常读取聊天正文的通用解密能力。


13. 群组和 Convo

群组数据仅面向有权限的成员展示。

被添加进 Convo 的用户仅获得 Convo 所允许的信息，不因此自动获得父群其他消息访问权。


14. 通话

Proxy 可以处理必要的通话元数据，例如：

- 参与者；
- 开始时间；
- 结束时间；
- 通话状态；
- 网络质量。

普通通话不会因为使用 Proxy 而自动被录音。


15. 录音

当用户主动使用录音功能时，应：

- 明确提示正在录音；
- 按法律要求取得同意；
- 控制录音访问权限；
- 提供相应删除机制。


16. 动态及公开内容

你选择公开发布的信息会按照你选择的范围被其他用户看到。

例如：

- Username；
- 头像；
- 动态；
- 评论；
- 活动；
- 机会。

因此，用户发布公开内容前应注意不要主动公开不希望他人知道的敏感个人数据。


17. 手机号隐私

手机号原则上是私人账号信息。

Proxy 不应因为两个用户：

- 成为好友；
- 加入同一个群；
- 参加同一个活动；
- 进行聊天

而自动向双方展示手机号。


18. 位置数据

Proxy 不会因为普通聊天持续公开用户实时位置。

只有在：

- 用户主动分享；
- 使用附近功能；
- 参加需要位置的功能；
- 使用导航或地图功能；

时，才根据必要范围处理位置。

用户可以通过设备系统设置撤销位置权限。


19. 活动、机会及邀约

为完成现实活动，Proxy 可能向相关参与者展示必要信息，例如：

- 时间；
- 大致地点；
- 活动内容；
- 用户公开身份；
- 服务范围。

Proxy 应避免向无关公众展示参与者不必要的实时精确位置。


20. 订单

为了创建和履行订单，Proxy 可以处理：

- 买方；
- 商家；
- 商品/服务；
- 金额；
- 时间；
- 地址；
- 订单状态；
- 售后；
- 退款。

只向完成对应交易所必要的主体提供数据。


21. 支付数据

Proxy 可以保存：

- 支付渠道；
- Transaction ID；
- 金额；
- 状态；
- 时间；
- Refund ID；
- 必要风险数据。

原则上，完整银行卡认证数据应由实际支付机构处理。


22. 商家数据

BUSINESS 用户可能需要提供：

- 企业名称；
- 企业代码；
- 地址；
- 联系人；
- 许可证；
- 税务信息；
- 银行结算信息；
- 门店信息。

依法要求向消费者公开的信息可以展示在商家页面。


23. 使用数据的目的

Proxy 主要为了：

- 创建账号；
- 身份验证；
- 保护账号；
- 提供消息；
- 提供群聊；
- 提供好友关系；
- 提供动态；
- 提供活动；
- 提供机会；
- 提供邀约；
- 提供商家服务；
- 处理订单；
- 处理支付状态；
- 防止诈骗；
- 内容安全；
- 客服；
- 处理投诉；
- 改善产品可靠性；
- 履行法律义务

处理数据。


24. 同意

当法律要求用户同意时，Proxy 应以：

- 清楚；
- 具体；
- 可理解；
- 可证明

的方式取得同意。

不得单纯以：

- 沉默；
- 预先勾选；
- 模糊行为

替代法律要求的有效同意。

对于不同处理目的，Proxy 应尽可能提供分目的、可管理的授权和撤回机制，而不是把与核心服务无直接必要关系的数据处理全部捆绑在注册动作中。

例如：

- 通讯录访问；
- 精确位置；
- 非必要 Cookie；
- 跨场景跟踪；
- 营销；
- 通话录音；
- 其他依法要求独立选择的处理

应在相应功能发生时提供适当说明和控制。


25. 撤回同意

如果某项数据处理依赖你的同意，你可以依法撤回该同意。

撤回同意不会使撤回前合法完成的数据处理自动变成违法。

如果某项数据是提供服务所必需的，撤回后相应功能可能无法继续运行。


26. 法律允许的非同意处理

越南法律在特定情况下可能允许不依赖用户同意处理数据，例如：

- 保护生命或健康的紧急情况；
- 履行法定义务；
- 依法响应有权国家机关；
- 法律规定的其他情况。

Proxy 只会在法律允许范围内使用这些例外。


27. 数据共享

Proxy 不会出售用户个人数据。

在以下必要情况下，Proxy 可以共享数据：

- 用户主动要求；
- 完成订单；
- 支付；
- 商家履约；
- 云计算；
- SMS；
- Email；
- Google 登录；
- 客服；
- 安全；
- 反欺诈；
- 法律义务。


28. 服务提供商

Proxy 可能使用外部服务提供商，例如：

- Cloud；
- CDN；
- Google Identity；
- SMS；
- Email；
- Payment；
- Analytics；
- Customer Support；
- Security。

Proxy 应仅允许这些服务商为了约定目的处理必要数据。


29. 第三方不得自行利用数据

服务提供商不得因为为 Proxy 提供技术服务，就擅自把 Proxy 用户数据用于与约定服务无关的用途。

Proxy 应通过：

- 合同；
- 权限；
- 技术控制；
- 安全要求

管理处理方。


30. 跨境数据传输

Proxy 可能使用全球技术和云服务，因此越南用户个人数据可能在越南境外进行处理。

如果发生跨境个人数据传输，Proxy 将按照越南适用法律建立、维护和提交必要的跨境数据处理文件和影响评估。


31. 数据保存

Proxy 不应无限期保存所有数据。

数据保存期限根据：

- 服务目的；
- 账号状态；
- 用户选择；
- 安全需要；
- 交易；
- 投诉；
- 税务；
- 法定保存要求

确定。

当数据不再需要时，应依法：

- 删除；
- 匿名化；
- 或采用其他允许的处理方式。


32. 账号删除

用户应可以请求注销 Proxy 账号。

账号注销后，应删除不再需要的个人数据。

但以下数据可能需要继续保存：

- 财务记录；
- 交易凭证；
- 税务资料；
- 欺诈证据；
- 投诉记录；
- 法律争议；
- 监管要求保存的信息。


33. 用户访问权

根据适用法律，你可以请求了解 Proxy 正在处理与你有关的个人数据。


34. 更正权

如果个人数据不准确，你可以要求更正。


35. 删除权

在法律规定的条件下，你可以请求删除个人数据。


36. 限制处理

在适用情况下，你可以要求限制某些个人数据处理。


37. 反对处理

在法律规定的范围内，你可以反对特定数据处理活动。


38. 数据提供

在适用情况下，你可以请求 Proxy 按法律要求向你提供自己的个人数据。


39. 投诉权

如果认为个人数据权利受到侵害，可以：

- 联系 Proxy；
- 提交投诉；
- 向有权主管机关反映；
- 依法采取其他救济措施。


40. 儿童数据

Proxy 对儿童数据实施额外保护。

涉及法律要求的儿童数据处理时，应依法取得：

- 儿童本人适当意思表示；
- 法定代表人同意；
- 或其他法律要求的授权。

不得将儿童数据用于违法剥削、诱导或其他有害目的。


41. AI 和自动化处理

Proxy 可以使用算法或 AI 用于：

- 搜索；
- 排序；
- 内容理解；
- 垃圾信息检测；
- 欺诈检测；
- 推荐；
- 平台安全；
- 产品辅助。

涉及依法需要额外通知、同意或人工复核的重要自动化决定时，将采取相应保护措施。


42. 营销

如果 Proxy 向用户发送营销消息，应遵守越南关于：

- 广告；
- 反垃圾信息；
- 个人数据；
- 消费者保护

的适用要求。

用户应能够关闭依法允许退出的营销通信。


43. Cookie 与“Do Not Track”选择

Web 版本可以使用必要 Cookie 维持：

- 登录；
- 安全；
- 会话；
- 语言；
- 基础功能。

对于社交网络和在线通信服务，Proxy 应向用户提供适用的 Cookie 拒绝选择。

对于依法需要额外同意的非必要 Cookie，应提供相应选择。

Proxy 还应提供适用的“不跟踪（Do Not Track）”选择，或仅在用户同意的情况下跟踪其使用社交网络、在线通信服务的活动。


44. 数据安全

Proxy 将根据风险采用合理安全措施，例如：

- 加密传输；
- 身份验证；
- 最小权限；
- Access Control；
- 日志；
- 安全监控；
- 密钥管理；
- 漏洞修复；
- 备份；
- 员工权限管理。

任何互联网系统都无法承诺绝对不存在风险。


45. 数据泄露及安全事件

发生个人数据安全事件时，Proxy 将：

1. 调查事件；
2. 控制风险；
3. 保存必要证据；
4. 评估影响；
5. 采取补救措施；
6. 在达到法定条件时向主管机关报告；
7. 在法律要求时通知受影响用户。


46. 数据处理影响评估

Proxy 将根据越南适用的个人数据保护要求，对个人数据处理建立必要的：

Data Protection Impact Assessment / 数据处理影响评估文件。

评估内容可包括：

- 数据类型；
- 数据主体；
- 处理目的；
- 数据流程；
- 处理方；
- 保存；
- 删除；
- 安全措施；
- 风险；
- 缓解措施。


47. 跨境数据影响评估

如果越南用户个人数据发生法律意义上的跨境传输，Proxy 将建立相应：

Cross-border Data Transfer Impact Assessment。

并依法维护、更新及办理必要程序。


48. Privacy Settings

Proxy 应逐步提供包括：

- 手机号发现；
- 通讯录同步；
- 在线状态；
- 好友权限；
- 位置；
- 消息请求；
- Mặc Kệ；
- Alias；
- 群组权限；
- Secure Chat；
- 营销设置；
- 账号删除

等隐私控制。


49. 政策更新

如果：

- 新增重要数据类别；
- 新增处理目的；
- 新增重大业务；
- 改变跨境路径；
- 法律发生变化；

Proxy 可以更新本政策。

对于法律要求重新取得用户同意的变化，将重新请求相应同意。

51. 账号验证数据

为履行越南网络安全和数字账号验证义务，Proxy 可以处理：

- 越南移动电话号码；
- 账号验证状态；
- 个人识别号码（仅在法律允许且必要时）；
- 合法电子身份验证结果；
- 验证时间、方式及必要审计记录。

上述数据仅用于身份验证、安全、法律合规及其他明确告知的合法目的。

完成验证不意味着 Proxy 可以把手机号、个人识别号码或其他验证数据公开给好友、群组成员、活动参与者或其他普通用户。


52. 社交网络和在线通信特别隐私规则

对于 Proxy 的社交网络和在线通信功能，我们应：

- 清楚说明安装和使用服务时收集哪些个人数据；
- 不超出已告知或合法范围收集数据；
- 为 Cookie 提供适用的拒绝选择；
- 提供“不跟踪”选择，或在取得用户同意后再跟踪相关使用活动；
- 不在没有用户同意或其他明确法律依据的情况下监听、录制通话或读取消息内容；
- 提供访问、更正、删除和隐私设置机制；
- 提供隐私和安全违规举报渠道；
- 对越南用户个人数据的跨境处理实施相应保护。

当法律依法授权有权机关访问或要求提供相关数据时，Proxy 将按照合法请求机制处理。


53. 系统日志保存

为了履行越南网络安全义务，Proxy 可以保存必要系统日志，包括：

- 用户账号；
- 登录和退出时间；
- IP；
- 登录和退出时的源端口；
- 已发布信息处理日志；
- 安全事件及账号处置记录。

适用网络安全日志应至少保持 12 个月可检索能力，法律要求更长时间的除外。

该日志保存属于平台安全和法律合规目的，不代表 Proxy 可以把日志用于与上述目的无关的营销或个人画像。


54. 合法政府请求

Proxy 仅在收到具有法律依据且来自有权机关的有效请求时，依法提供必要用户信息或执行相关网络安全措施。

Proxy 将建立请求验证、最小化披露、访问控制、内部审批和处理日志机制。

在适用网络安全规则要求下，Proxy 应具备满足一般 24 小时及特定紧急情形 3 小时的信息响应能力，以及违法信息处置的一般 24 小时和国家安全紧急情形 6 小时响应能力。


55. 数据处理影响评估与更新

Proxy 将依据越南《个人数据保护法》及其实施规定建立个人数据处理影响评估文件。

当处理活动、组织结构、数据类别、处理目的、技术架构、处理方或其他法定事项发生变化时，应按照适用法律更新影响评估。

相关影响评估文件还应按照现行规则进行定期审查和必要更新。


56. 跨境数据影响评估

如果越南用户个人数据发生法律意义上的跨境传输，Proxy 将：

- 识别数据接收方和传输路径；
- 记录传输目的、数据类型和保护措施；
- 建立跨境个人数据传输影响评估文件；
- 按越南法律要求提交、维护和更新；
- 对云服务、AI 服务、CDN、支付、分析及其他境外处理方进行相应评估。


57. 电子商务和商家数据

当 Proxy 构成越南法律定义的开展电子商务活动的社交网络、电子商务平台或其他受监管平台时，我们可能依法处理和保存：

- 商家身份验证数据；
- 企业或经营主体信息；
- 商品及服务信息；
- 订单和交易记录；
- 消费者投诉；
- 平台处置记录；
- 税务、发票或依法要求提供的数据。

这些数据只在交易履行、消费者保护、税务、平台治理、安全和法律义务所需要的范围内处理。

本中文稿截至 2026-08-31，根据 Proxy 当前功能并结合越南现行个人数据、网络安全、电子商务、消费者保护、电子交易及相关法律制度更新。
